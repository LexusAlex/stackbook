# Буква и звук

**Около 5 минут: послушайте два слова, сравните их и проверьте новое слово по готовой карточке.** Все аудио, объяснения и задания находятся здесь.

Нажмите **▶** у каждого слова и повторите вслух.

В обоих словах есть буква **a**, но звучит она по-разному: /æ/ и /eɪ/. Конечная **e** в cake отдельно не произносится. Это наблюдения об этих словах; для нового слова звучание нужно проверять по аудио.

## 2. Разделите буквы и звуки

| Что видим | Что это |
| --- | --- |
| **cat** | Написание слова «кошка» |
| **C — A — T** | Его буквы по отдельности: /siː/ — /eɪ/ — /tiː/ |
| **/kæt/** | Запись произношения слова целиком |

Буквы мы видим и пишем, звуки — слышим и произносим. Запись произношения между косыми чертами называется **транскрипцией**. Называть C, A и T нужно, когда диктуете написание; само слово звучит как в первом плеере.

<LessonCheck question="Что показывает /kæt/?" :options="['Названия трёх букв', 'Произношение слова целиком', 'Перевод слова']" :correct="1" explanation="Это транскрипция — запись произношения слова cat." />

Словарная карточка уже подготовлена. Откройте её, найдите значение, затем **UK** — британский вариант произношения — и транскрипцию. Нажмите **▶** и произнесите слово два раза.

Закройте карточку и скажите **bag** ещё раз. Затем откройте её и послушайте для сравнения. Проверяйте слово целиком; перечислять названия букв сейчас не нужно.

## Для следующего занятия: ещё три слова

Открывайте по одной карточке. Послушайте, повторите, затем закройте и попробуйте сказать слово по памяти.

::: details book — книга

**UK /bʊk/**. Две буквы **oo** в этом слове передают /ʊ/.
