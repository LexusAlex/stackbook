# Английский алфавит

**После урока вы сможете найти буквы своего имени в английском алфавите и назвать их по-английски.** Для этого послушаем названия букв, сопоставим большие и маленькие формы и сделаем короткую запись голоса.

Ориентир — 25–35 минут. Алфавит содержит 26 букв, поэтому работайте небольшими частями. В первую очередь потренируйте буквы своего имени; остальные можно закреплять в несколько коротких подходов.

Перед началом повторите две-три карточки из урока [«Повторение слов и выражений»](./reviewing-words-and-phrases), для которых подошла дата проверки. Затем переходите к новому материалу.

## 1. Подготовьте заметку и своё имя

1. Откройте свою учебную заметку и добавьте раздел **«Английский — урок 3»**.
2. Запишите своё имя английскими буквами в привычном вам варианте. Например: Анна → `Anna`, Нина → `Nina`. Если пока не знаете написание, начните с учебного примера `Anna`, а перед итоговой проверкой уточните написание своего имени.
3. Подготовьте диктофон, как в первом уроке.
4. Скопируйте шаблон. Сейчас заполните дату и имя, остальные строки — по ходу работы.

```text
Дата:
Моё имя английскими буквами:
Буквы имени по отдельности:
Какие большие и маленькие буквы перепутал:
Аудирование — первые четыре буквы, попытка 1:
Аудирование — попытка 2, если понадобилась:
Как назвал буквы имени без таблицы:
Что ещё нужно повторить:
Имя файла с записью:
Дата следующей проверки:
```

**Результат шага:** имя записано, есть место для ответов и будущей записи.

## 2. Послушайте названия букв

В английском алфавите **26 букв**. У каждой есть прописная, то есть большая, и строчная, то есть маленькая, форма: например, `A` и `a` — одна буква.

Когда вы называете буквы имени по отдельности, используются **названия букв**. Они не задают один неизменный звук для всех слов: правила чтения будем разбирать отдельно. Сегодня задача — услышать название и узнать соответствующую букву.

1. Нажмите **▶** и один раз послушайте алфавит целиком. Запись длится около 31 секунды.
2. Во время прослушивания ведите взглядом по таблице ниже: A, B, C и дальше по порядку.
3. Включите запись снова. Делайте паузу после нескольких букв и повторяйте их вслух.
4. Работайте порциями: **A–G**, затем **H–N**, **O–T**, **U–Z**. Если устали, оставьте часть букв на следующий короткий подход.

## 3. Узнайте буквы в разных формах

Часть английских букв похожа на русские, но их названия отличаются. Например, английскую `B` нужно назвать так, как она звучит в записи. При письме на компьютере переключите раскладку на английскую.

1. Посмотрите на шесть маленьких букв: **b, d, g, h, r, y**.
2. Напишите для каждой соответствующую большую букву в том же порядке. Сначала попробуйте без таблицы.
3. Затем перепишите имя **Anna** большими буквами. Сохраните все буквы, в том числе повторяющиеся.
4. Только после своей попытки откройте проверку.

::: details Проверить большие и маленькие буквы

- `b, d, g, h, r, y` → **B, D, G, H, R, Y**.
- `Anna` → **ANNA**: четыре буквы, N встречается два раза.

Если перепутали пару, найдите её в таблице и напишите рядом обе формы, например `G — g`. Затем закройте таблицу и попробуйте эту пару снова.

:::

**Что сохранить:** свой ответ и конкретные перепутанные пары. Если всё верно, напишите «формы букв сопоставил без ошибки».

## 4. Запишите буквы на слух

В следующей записи буквы идут **в другом порядке**, группами по звучанию. Сейчас нужна только самая первая группа — **четыре буквы**. Ответ скрыт ниже.

1. Сверните ответы и не смотрите на таблицу.
2. Нажмите **▶** во втором плеере и запишите первые четыре названия как буквы: `1. ... 2. ... 3. ... 4. ...`.
3. После четвёртой буквы поставьте запись на паузу. Дальше начнётся другая группа.
4. При необходимости верните запись к началу и послушайте ещё раз. Вторую попытку запишите отдельно.
5. Откройте ответ и сравните каждую позицию.

::: details Проверить первые четыре буквы на слух

Первая группа: **A — H — J — K**.

Если получилось, например, `A — H — G — K`, отметьте, что перепутаны G и J. Найдите обе буквы в первой записи: у G название /dʒiː/, у J — /dʒeɪ/. Послушайте и повторите их по отдельности, затем снова вернитесь к заданию.

Если пока не удалось узнать ни одной буквы, откройте ответ, послушайте первые четыре с открытым текстом и повторите. Сохраните пометку «с ответом», затем позже попробуйте без него.

:::

**Что сохранить:** результат первой попытки, результат повтора и буквы, которые пришлось разобрать с помощью.

## 5. Назовите буквы своего имени

Теперь применим алфавит к своей задаче.

1. Вернитесь к имени из шага 1. Под ним напишите каждую букву отдельно: например, `Alex` → **A — L — E — X**.
2. Найдите эти буквы в таблице и в первой записи. Послушайте их названия и произнесите каждое вслух.
3. Назовите всю последовательность медленно, делая небольшую паузу между буквами. Для `Alex` это A, затем L, затем E, затем X. Произнесите именно английские названия из аудио.
4. Закройте таблицу, посмотрите только на написанное имя и снова назовите его буквы.
5. Включите диктофон. Сначала скажите знакомую фразу **My name's ...**, подставив своё имя. Затем назовите буквы имени по очереди.
6. Сохраните запись как `lesson-03-alphabet` и впишите имя файла в заметку.

Ещё один пример: `Anna` → **A — N — N — A**. Два N называются по отдельности: сегодня достаточно повторить название буквы два раза.

**Как проверить себя:** все ли буквы названы, не пропущены ли повторяющиеся и сохранён ли порядок? Если занимаетесь с собеседником, попросите его записать услышанные буквы и сравните с именем. Если занимаетесь один, прослушайте свою запись, проверяя последовательность по написанному имени. Для сомнительного произношения снова используйте аудио или помощь преподавателя.

Если пока получается только с таблицей, сохраните пометку «с таблицей» и потренируйте нужные буквы ещё раз. Затем сделайте отдельную попытку без подсказки.

## 6. Заполните итог и назначьте повторение

Пример заметки **вымышленного ученика Alex**:

```text
Дата: 25.10.2026
Моё имя английскими буквами: Alex.
Буквы имени по отдельности: A — L — E — X.
Какие большие и маленькие буквы перепутал: сначала G и g, потом исправил.
Аудирование — первые четыре буквы, попытка 1: A — H — G — K.
Аудирование — попытка 2, если понадобилась: A — H — J — K.
Как назвал буквы имени без таблицы: получилось после двух повторов.
Что ещё нужно повторить: E и I; G и J.
Имя файла с записью: lesson-03-alphabet.
Дата следующей проверки: 26.10.2026.
```

Сегодняшняя работа завершена, когда вы:

- сопоставили большие и маленькие буквы и проверили ответы;
- сделали попытку записать четыре буквы на слух, сохранили результат и разобрали ошибки;
- записали своё имя отдельными буквами и попробовали назвать их без таблицы;
- сохранили короткую запись голоса и отметили, где ещё нужна подсказка;
- выбрали дату следующего короткого повторения, например завтра.

В следующую проверку сначала назовите буквы своего имени без таблицы. Если забываете отдельные буквы, добавьте по одной карточке по образцу предыдущего урока: на лицевой стороне буква, на обороте её название и ссылка на запись.

Для нового примера попробуйте назвать буквы имени **Mia**, затем откройте проверку.

::: details Проверить новый пример

`Mia` → **M — I — A**. Названия: /em/ — /aɪ/ — /eɪ/.

:::

Продолжайте короткими порциями закреплять остальные буквы. Уверенно назвать буквы своего имени — первый практический результат, а воспроизведение всего алфавита можно постепенно довести до свободного.
