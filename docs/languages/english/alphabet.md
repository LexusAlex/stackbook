# Английский алфавит

**Около 5 минут: послушайте буквы и назовите буквы своего имени.** Плееры, таблица и проверка находятся здесь. Можно начать с имени Alex, а затем попробовать своё.

## 1. Послушайте алфавит

Нажмите **▶**: запись длится около 31 секунды. Раскройте таблицу ниже и следите за буквами. При повторном прослушивании ставьте на паузу и повторяйте небольшими группами: **A–G**, **H–N**, **O–T**, **U–Z**.

::: details Таблица A–Z: большие и маленькие буквы

**Прописная** — большая буква, **строчная** — маленькая. A и a — одна и та же буква. Последний столбец — запись её названия; если символы незнакомы, ориентируйтесь на аудио.

| Прописная | Строчная | Название: справка |
| --- | --- | --- |
| A | a | /eɪ/ |
| B | b | /biː/ |
| C | c | /siː/ |
| D | d | /diː/ |
| E | e | /iː/ |
| F | f | /ef/ |
| G | g | /dʒiː/ |
| H | h | /eɪtʃ/ |
| I | i | /aɪ/ |
| J | j | /dʒeɪ/ |
| K | k | /keɪ/ |
| L | l | /el/ |
| M | m | /em/ |
| N | n | /en/ |
| O | o | /əʊ/ |
| P | p | /piː/ |
| Q | q | /kjuː/ |
| R | r | /ɑː/ |
| S | s | /es/ |
| T | t | /tiː/ |
| U | u | /juː/ |

| Y | y | /waɪ/ |
| Z | z | /zed/ |

В этой записи британский вариант: **Z — zed**. В американском английском Z также называют **zee**, /ziː/.

## 3. Назовите буквы имени

Впишите имя латинскими буквами или оставьте Alex. Назовите каждую букву по-английски, сверяясь с аудио и таблицей выше. Нажмите **«Скрыть образец»**, повторите без него и откройте для проверки порядка.

<LessonName mode="alphabet" />

У **Anna** четыре буквы: **A — N — N — A**. Название N произносится два раза. Здесь нужно называть буквы по отдельности; произношение слова целиком разберём в [следующем уроке](./letters-and-sounds).

**На сегодня достаточно:** вы узнали большую букву и попробовали назвать буквы имени. Если пяти минут не хватило, продолжите отсюда в следующий раз.

**Mia → M — I — A**, названия: /em/ — /aɪ/ — /eɪ/.
