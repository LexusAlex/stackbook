# Что такое Linux

После этой статьи вы сможете объяснить, за что отвечает ядро Linux, зачем нужны системные программы и что добавляет дистрибутив.

## Перед началом

Достаточно браузера и заметки для ответов. Практика в этой статье — разобрать состав системы и объяснить роли её частей на примере веб-сервера.

## 1. Что называют Linux

**Linux — ядро операционной системы:** основная часть, через которую работающие программы получают доступ к ресурсам компьютера.

В повседневной речи словом «Linux» также называют целую систему на этом ядре — например, установленную Ubuntu или Debian. Поэтому фраза «установить Linux» обычно означает установить один из дистрибутивов. Различие между ядром и системой описано в [FAQ Debian](https://www.debian.org/doc/manuals/debian-faq/basic-defs).

Чтобы понимать устройство сервера, будем различать ядро, системные программы и приложения.

## 2. За что отвечает ядро

Одновременно на сервере могут работать веб-сервер, база данных и другие программы. Ядро управляет общими ресурсами:

- распределяет время процессора между выполняющимися процессами;
- управляет памятью;
- предоставляет операции работы с файлами и сетевыми соединениями;
- обеспечивает взаимодействие с устройствами через драйверы.

Например, программа обращается к файлу через возможности ОС, а не управляет диском самостоятельно. На виртуальной машине ядро работает с предоставленными ей виртуальными устройствами.

Поддержка многозадачности, памяти и сети описана на странице [About Linux Kernel](https://www.kernel.org/linux.html).

## 3. Какие программы работают рядом с ядром

Для повседневной работы нужны инструменты управления системой и программы, решающие задачи пользователя.

| Часть системы | Примеры | Что делает |
| --- | --- | --- |
| Ядро | Linux | Управляет ресурсами и предоставляет доступ к ним |
| Системные программы | Bash, systemd, APT | Позволяют выполнять команды, управлять службами и устанавливать пакеты |
| Прикладные программы | Nginx, текстовый редактор | Обслуживают сайт, редактируют документы и решают другие задачи |
| Оборудование | Процессор, оперативная память, диск | Предоставляет вычислительные ресурсы и хранение данных |

Несколько названий из таблицы встретятся дальше:

- **Bash** — оболочка: разбирает введённые команды и выполняет их. Его назначение описано в [руководстве Bash](https://www.gnu.org/software/bash/manual/html_node/What-is-Bash_003f.html).
- **systemd** управляет запуском и работой служб. Служба — программа, работающая в фоне, например веб-сервер. Подробнее — в [руководстве systemd](https://freedesktop.org/software/systemd/man/latest/init.html).
- **APT** управляет пакетами программ в Debian и Ubuntu. Пакет содержит подготовленную для установки программу или другие компоненты. [Описание APT в составе Debian](https://www.debian.org/intro/about).

Системные и прикладные программы тоже обращаются к ядру. Такое деление помогает понять их назначение: Bash принимает команды, APT устанавливает программы, Nginx обслуживает сайт.

## 4. Пример: сервер отдаёт страницу

Представим, что на сервере настроен Nginx, который отдаёт HTML-файл:

1. Браузер отправляет запрос страницы.
2. Nginx обрабатывает запрос и определяет, какой файл нужен.
3. Для чтения файла и передачи данных по сети Nginx использует возможности ядра.
4. Браузер получает ответ и показывает страницу.

**Логику ответа веб-сервера определяет Nginx; доступ к файлам и сети обеспечивает ядро.** Назначение Nginx как HTTP-сервера описано в [документации проекта](https://nginx.org/en/).

Если нужно обслуживать сайт, устанавливают и настраивают веб-сервер. Эта задача сама по себе не требует замены ядра.

## 5. Что добавляет дистрибутив

**Дистрибутив** объединяет ядро, системные программы и другие компоненты в систему, которую можно установить и обновлять. Проект дистрибутива подготавливает пакеты, поддерживает их совместную работу и предоставляет инструменты управления ими.

Ubuntu и Debian — примеры дистрибутивов на ядре Linux. Набор программ, настройки и версии компонентов у них могут различаться. Отдельные приложения устанавливаются по мере необходимости.

Именно дистрибутив мы будем устанавливать на учебную машину. О роли ядра, базовых инструментов и пакетов можно прочитать во [введении Debian](https://www.debian.org/intro/about). Выбор дистрибутива и релиза — тема следующей статьи плана.

## 6. Проверьте себя

В заметке распределите названия по пяти группам: **ядро, системная программа, прикладная программа, дистрибутив, оборудование**.

1. Linux — в точном значении этого слова.
2. Bash.
3. systemd.
4. APT.
5. Nginx.
6. Ubuntu.
7. SSD.

Затем ответьте своими словами:

- Какую роль играет ядро, когда Nginx читает файл?
- Почему для установки системы выбирают дистрибутив?
- К какой части системы относится программа для редактирования текста?

Откройте ответы после своей попытки.

::: details Ответы и объяснение

| Название | Группа |
| --- | --- |
| Linux | Ядро |
| Bash | Системная программа: оболочка |
| systemd | Системная программа: управление службами |
| APT | Системная программа: управление пакетами |
| Nginx | Прикладная программа: веб-сервер |
| Ubuntu | Дистрибутив |
| SSD | Оборудование |

При чтении файла ядро предоставляет Nginx доступ через файловую систему и обслуживает необходимые операции ввода-вывода. Какой файл нужен для ответа, определяет веб-сервер.

Дистрибутив объединяет ядро с базовыми программами и инструментами установки и обновления. Это подготовленная к использованию система.

Текстовый редактор — прикладная программа. Он выполняет задачу пользователя, используя возможности ОС.

:::
