# План статей по Docker

Цель серии — небольшими итерациями пройти от первого контейнера до самостоятельной сборки и запуска приложения с PostgreSQL и Nginx.

Каждый пункт с номером — отдельная короткая статья об одном понятии, приёме или задаче. Разделы только объединяют связанные статьи. У каждой статьи есть собственный проверяемый результат; практические примеры по возможности продолжают один учебный проект.

Основной маршрут — статьи 1–64. Статьи об установке на Linux, Windows и macOS альтернативные: читатель выбирает свою ОС. Статьи 65–82 предназначены для дальнейшего углубления.

Перед началом полезно освоить базовые команды терминала, работу с файлами, понятия процесса, IP-адреса и порта. Основы YAML вводятся перед первым файлом Compose.

## Итоговый учебный проект

Небольшое веб-приложение, PostgreSQL и Nginx. Язык приложения можно выбрать по своему опыту; он остаётся одним и тем же во всей серии.

Критерии готовности:

- Локальное окружение запускается командой `docker compose up -d --build`.
- Nginx принимает HTTP-запросы и передаёт их приложению.
- Приложение подключается к PostgreSQL через внутреннюю сеть.
- Данные сохраняются после пересоздания контейнеров.
- Создание и восстановление резервной копии проверены на тестовой базе.
- Готовность сервисов видна, ошибки можно найти по логам.
- Секреты не попадают в Git и образ приложения.
- На сервере используется опубликованный образ с явной версией.
- Обновление приложения и откат образа проверены; ограничения после миграций БД описаны отдельно.

Чекбокс у статьи отмечается после подготовки русской и английской версий, проверки описанных команд и конфигурации, а также проверки сборки, меню и поиска. Подготовленный текст без практической проверки остаётся неотмеченным; выполненные проверки и ограничения записываются рядом с пунктом.

Наличие пункта в плане означает только запланированную статью. Файлы и пункты меню добавляются по мере подготовки материалов.
