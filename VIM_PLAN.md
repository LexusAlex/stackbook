# План статей по изучению Vim

Цель серии — небольшими итерациями освоить редактирование текста в Vim: уверенно перемещаться по файлу, вносить изменения, работать с несколькими файлами и повторять однотипные действия.

Каждый пункт с номером — отдельная короткая статья с одной задачей, практикой и проверяемым результатом. Основной маршрут — статьи 1–64. Статьи 65–80 помогают расширить набор приёмов после освоения основ.

## Учебное окружение

- Vim и терминал своей ОС. Установка описывается для выбранной системы; перед упражнениями проверяются `vim --version` и доступные возможности сборки.
- Отдельный каталог `vim-practice` с файлами `notes.txt`, `tasks.txt` и `settings.txt`. Все изменения выполняются на учебных копиях.
- Начальные занятия проходят без сторонних плагинов. Настройки вводятся по одной, после знакомства с обычным поведением редактора.
- Используется Vim. Отличия Neovim и расширений с Vim-режимом объясняются там, где они влияют на пример.
- Команды терминала и команды внутри Vim показываются раздельно. Для PowerShell и Bash указываются подходящие пути и способы подготовки файлов.
- Команды вводятся на латинской раскладке; текст учебных файлов может быть на русском.

Первые упражнения опираются на [руководство Vim для начинающих](https://vimhelp.org/usr_02.txt.html). Справочник доступен и внутри редактора через `:help`.

## Как проходить небольшую итерацию

1. Прочитать объяснение одного приёма и ожидаемый результат.
2. Открыть небольшой исходный файл, указанный в статье.
3. Выполнить последовательность клавиш, обращая внимание на текущий режим.
4. Сравнить текст в буфере с ожидаемым результатом; при сохранении проверить файл на диске.
5. Повторить приём на другом фрагменте без подсказки.
6. Записать одну трудность и вернуться к ней на следующем занятии.

Ориентир — 10–20 минут на новую тему и несколько минут повторения. Обозначения вроде `Esc`, `Enter` и `Ctrl-r` объясняются перед первым использованием; Enter для команд с двоеточием указывается явно.

## Итоговый учебный проект

Небольшой набор заметок и задач, который редактируется в Vim без сторонних плагинов.

Критерии готовности:

- Читатель открывает файл, вводит текст, сохраняет его и выходит.
- Нужный фрагмент находится через перемещение или поиск.
- Изменения отменяются и возвращаются с пониманием результата.
- Текст копируется и переносится внутри файла и между буферами.
- Замены ограничиваются нужными строками и проверяются перед сохранением.
- Два файла открываются одновременно, понятна разница между буфером и окном.
- Один макрос применяет одинаковую правку к нескольким строкам.
- Минимальная конфигурация воспроизводится при новом запуске.
- На учебном примере восстановленный после сбоя текст сохраняется отдельной копией.
- Окончательный результат проверен повторным открытием файлов.

Перед командами с потерей несохранённого текста показываются исходное состояние и последствия. Материал заканчивается проверкой результата; переходы между статьями доступны через меню сайта.

## Отметки готовности

Чекбокс означает готовность статьи в проекте. Он отмечается после подготовки русской и английской версий, проверки последовательности клавиш на указанной версии Vim, проверки сохранённых файлов, сборки, меню и поиска.

Для платформенных особенностей фиксируются ОС, терминал и нужные возможности сборки. Учебный прогресс читателя ведётся отдельно от готовности публикаций. Файлы статей и пункты меню добавляются по мере подготовки материалов.
